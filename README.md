# Serfinanza Action Hub

Prototipo de hackathon para un copiloto contextual de atencion presencial. La app ayuda al asesor durante la conversacion con un cliente, detecta consultas bancarias, muestra asistencia estructurada y convierte los eventos en insumos para calidad, administracion de brechas y marketing.

## Donde empezar

- Estado actual del producto: `docs/current/PROJECT_STATUS.md`
- Especificacion funcional: `docs/current/SERFINANZA_ACTION_HUB_SPEC.md`
- Especificacion tecnica: `docs/current/TECHNICAL_SPEC.md`
- Guion de demo: `docs/current/DEMO_SCRIPT.md`
- Experimento de voz local: `docs/LOCAL_WHISPER_EXPERIMENT.md`
- Decisiones tecnicas: `docs/decisions/`

## Carpetas

- `prototype/`: aplicacion Next.js.
- `voice-agent/`: servicio local Python para microfono + Whisper.
- `DocumentoSERFINANZA/`: insumos originales del reto y documentos fuente.
- `docs/current/`: documentos vivos del producto.
- `docs/history/`: exploraciones, versiones anteriores y contexto archivado.
- `docs/testing/`: frases y material de prueba.
