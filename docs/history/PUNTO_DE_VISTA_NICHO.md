# Punto De Vista De Nicho - Serfinanza Action Hub

## 1. Contexto

Serfinanza Action Hub nace con un outcome amplio:

> Aumentar la resolucion personalizada y segura de necesidades financieras en el primer contacto, convirtiendo conocimiento bancario aprobado en la siguiente mejor accion para cada cliente o asesor.

Ese outcome es correcto, pero para una hackathon puede quedar demasiado abierto. Otros equipos pueden llegar a una solucion similar: chatbot con RAG, respuestas sobre productos y algun dashboard de metricas.

Para diferenciarnos, necesitamos enfocar el producto en un nicho claro, con dolor especifico y demostrable.

## 2. Riesgo Del Enfoque Amplio

Si planteamos el producto como "un agente 360 para clientes y asesores", corremos tres riesgos:

- Parecer un chatbot bancario generico.
- Intentar cubrir demasiados productos, canales y usuarios.
- Diluir la conexion entre atencion, adquisicion digital y pagos agenticos.

El problema no es que la vision sea incorrecta. El problema es que una vision demasiado amplia es dificil de demostrar y facil de copiar en una hackathon.

## 3. Nicho Recomendado

El nicho recomendado es:

> Asesores de primera linea que atienden solicitudes de actualizacion de datos, canales digitales e intencion de adquisicion de productos de ahorro/inversion.

Version mas directa:

> Serfinanza Action Hub para asesores de atencion y adquisicion digital.

Este nicho concentra el producto en el punto donde se cruzan:

- conocimiento bancario;
- atencion al cliente;
- consistencia operativa;
- canales digitales;
- adquisicion de productos;
- aprendizaje desde interacciones reales.

## 4. Tesis Del Nicho

Los asesores de primera linea son un punto critico porque convierten conocimiento bancario en decisiones operativas frente al cliente.

Cuando un asesor no encuentra informacion clara o actualizada:

- el cliente espera mas;
- la respuesta varia entre canales;
- aumenta el riesgo de error;
- se pierden oportunidades de conversion;
- el banco no aprende sistematicamente de las preguntas reales.

Serfinanza Action Hub debe ayudar al asesor a resolver mejor desde el primer contacto y, al mismo tiempo, convertir esas interacciones en inteligencia para mejorar contenido, procesos y adquisicion digital.

## 5. Nueva Formulacion Del Producto

Formulacion anterior:

> Convertimos conocimiento bancario aprobado en la siguiente mejor accion personalizada para clientes y asesores.

Formulacion enfocada:

> Convertimos el conocimiento publico y documental de Serfinanza en decisiones operativas para asesores de primera linea, ayudandoles a resolver solicitudes frecuentes, orientar al cliente al canal correcto y detectar oportunidades reales de adquisicion digital.

## 6. Por Que Este Nicho Es Mas Competitivo

Este nicho es mas fuerte para hackathon porque:

- Se alinea con el caso principal de demo: actualizacion de datos para asesor.
- Tiene dolor concreto: inconsistencia, espera, errores y curva de aprendizaje.
- Evita competir directamente como "otro chatbot para clientes".
- Permite demostrar impacto interno y externo a la vez.
- Usa la web y documentos del banco como fuentes de conocimiento.
- Conecta adquisicion digital sin forzarla.
- Permite cerrar con CDT como oportunidad de conversion.
- Hace que Knowledge Intelligence sea natural: el banco aprende de lo que preguntan clientes y asesores.

## 7. Alcance De Indexacion Web

Para el MVP no se debe indexar toda la web del banco sin criterio. Eso aumentaria ruido y riesgo de respuestas imprecisas.

Se recomienda priorizar paginas y contenidos relacionados con:

1. Actualizacion de datos.
2. Canales de atencion.
3. Preguntas frecuentes.
4. CDT y CDT Digital.
5. CliCuenta.
6. Tarjeta de credito.
7. Tasas y tarifas.
8. Canales de pago, PSE y Serfinanza Virtual.

Fuera de foco inicial:

- Productos empresariales complejos.
- Leasing.
- Factoring.
- Seguros.
- Gobierno corporativo.
- Informacion institucional no accionable.

## 8. Demo Replanteada

### Escena 1 - Asesor Resuelve Actualizacion De Datos

El asesor pregunta:

> "Cliente quiere cambiar ingresos y direccion por WhatsApp. Se puede?"

El sistema responde con:

- distincion entre tipos de datos;
- canal recomendado;
- checklist operativo;
- documentos o soportes;
- criterio de escalamiento;
- fuente consultada;
- siguiente mejor accion.

Esta escena demuestra resolucion en primer contacto y soporte al asesor.

### Escena 2 - Asesor Orienta Intencion De Inversion

El asesor recibe una pregunta de cliente:

> "Tengo 5 millones y quiero invertirlos 180 dias. Que le puedo recomendar?"

El sistema responde con:

- explicacion clara de CDT/CDT Digital;
- datos interpretados: monto y plazo;
- advertencias sobre tasas y condiciones;
- siguiente mejor accion: simular CDT, iniciar solicitud o derivar a canal adecuado;
- fuente consultada.

Esta escena demuestra adquisicion digital asistida.

### Escena 3 - Knowledge Intelligence

El dashboard muestra:

- consultas frecuentes por tema;
- vacios de conocimiento;
- respuestas sin fuente suficiente;
- oportunidades de contenido;
- intenciones de adquisicion detectadas;
- procesos que generan friccion.

Esta escena demuestra que el banco aprende de las interacciones, no solo responde.

## 9. Rol De La Pagina Web Del Banco

La pagina web de Banco Serfinanza debe funcionar como fuente complementaria de conocimiento publico.

Su rol en el MVP:

- Ampliar la base documental mas alla de los PDFs del reto.
- Permitir respuestas con fuentes publicas.
- Detectar contenido existente que puede reutilizarse.
- Identificar vacios o inconsistencias entre documentos y web.
- Alimentar oportunidades de contenido para Knowledge Intelligence.

No debe usarse como excusa para responder todo. La indexacion debe estar acotada por el nicho.

## 10. Relacion Con Pagos Agenticos

El nicho no abandona la vision agentica. La ordena.

Primero:

- conocimiento confiable;
- asesor mejor informado;
- siguiente mejor accion;
- trazabilidad;
- escalamiento.

Luego:

- acciones financieras preparadas;
- consentimiento;
- limites;
- auditoria;
- ejecucion controlada.

La tesis agentica queda como evolucion:

> Antes de que un agente pueda ejecutar acciones financieras, el banco debe demostrar que sabe convertir conocimiento en acciones seguras, explicables y trazables.

## 11. Mensaje Para Mentor

Serfinanza Action Hub no es un chatbot generico para responder preguntas bancarias. Es una herramienta enfocada en asesores de primera linea que convierte conocimiento publico y documental del banco en decisiones operativas: que decir, por que canal continuar, que documentos pedir, cuando escalar y cual es la siguiente mejor accion para el cliente.

El producto abre resolviendo un caso frecuente de actualizacion de datos y cierra mostrando como una intencion de inversion puede convertirse en una ruta de adquisicion de CDT. Ademas, cada interaccion alimenta una capa de Knowledge Intelligence que detecta vacios de conocimiento, oportunidades de contenido y fricciones reales en atencion.

## 12. Decision Recomendada

Adoptar este nicho como foco del MVP:

> Asesores de primera linea en atencion y adquisicion digital.

Mantener cliente externo y pagos agenticos como expansion futura o escenas complementarias, no como centro del primer prototipo.
